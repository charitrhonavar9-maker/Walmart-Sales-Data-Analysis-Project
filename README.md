# Walmart Sales Data Analysis

This project focuses on analyzing Walmart sales data using Python, Pandas, and SQL in Jupyter Notebook. The project includes data cleaning, transformation, exploratory data analysis (EDA), and solving 9 real-world business problems to generate meaningful business insights.

## Tools & Technologies Used
* Python
* Pandas
* MySQL / SQL
* Jupyter Notebook

## Project Highlights
* Cleaned and processed raw Walmart sales data
* Handled missing values and data formatting
* Performed SQL queries for business analysis
* Solved 9 business problems using data analysis techniques
* Generated insights on sales performance, customer behavior, product trends, and revenue patterns
* Used Python and Pandas for data manipulation and analysis

## Outcome

This project helped strengthen practical skills in:
* Data Cleaning
* Data Analysis
* SQL Query Writing
* Business Insight Generation
* Data Visualization
* Problem Solving using Real-world Data
